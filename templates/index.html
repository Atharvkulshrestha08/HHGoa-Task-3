Task #3 Specification

Face ID + Blockchain Verification

PIPELINE ARCHITECTURE

How the Cryptographic Verification Pipeline Works

Strictly engineered end-to-end to fulfill every evaluation criterion of HH Goa Task #3.

01

Biometric Face Ingestion

Input image is parsed through OpenCV YuNet deep neural network. Detects 5-point facial landmarks (eyes, nose, mouth corners) and calculates strict confidence bounding box.

OpenCV YuNet + Haar
02

128-d Vector Encoding

Face is cropped, normalized to 112×112px, and fed into SFace deep metric model. Generates a high-dimensional 128-float unit hypersphere embedding vector with SHA-256 digest.

128-d SFace Embedding
03

Live Reverse Search

Executes genuine reverse search across Google Lens / SerpAPI and live Wikidata entity SPARQL resolution to discover real, authentic matching social media posts on X/Twitter, Instagram, or LinkedIn.

Real Social Match URL
04

Blockchain Notarization

Combines image hash + embedding + discovered post URL into a canonical payload. Computes Keccak-256 (bytes32) and broadcasts on-chain transaction to Ganache / Sepolia / Local EVM.

Keccak-256 EVM CallData
